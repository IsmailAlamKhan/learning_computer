# TASK: Write and wire up the following modules in Bengali for both Windows and Mac.

Module 7: Internet and browser. What the internet is; Wi-Fi vs mobile data; what a browser is (Chrome, Edge, Safari); address bar vs search bar; tabs; back/forward/refresh; bookmarks; searching effectively in Bengali and English; reading search results; spotting trustworthy vs suspicious sites; downloading safely and finding the download afterwards. Build a simulated mini-internet (a few fake sites: a recipe site, a news site, a search engine page, a fake suspicious site) inside the simulated browser. No real network requests.

Module 8: Email and online accounts. Simulated email client: inbox, compose, to/subject/body, attachments (from the virtual file system), reply/forward, spam folder. Explain what an online account is, why an email address is needed for things like GitHub, and good account habits.

Module 9: Safety and security. Strong passwords and not reusing them; password managers; two-factor authentication; never sharing OTP/PIN; phishing emails and fake links; fake prize/lottery messages; fake bKash/Nagad/bank calls and SMS (realistic Bangladeshi context, with clearly fictional numbers and names); safe public Wi-Fi; updates and antivirus basics; locking the screen (Win+L / Ctrl+Cmd+Q); privacy basics. Include interactive "Spot the scam" exercises using simulated messages.

Module 10: Settings and personalization. Wallpaper, brightness, volume, text size, connecting to Wi-Fi, date/time/timezone (Asia/Dhaka), Bluetooth/printer (simulated), language/keyboard, display zoom.

Module 11: Photos, media, screenshots, and devices. Viewing photos; playing video and music; screenshots (Win+Shift+S / PrtScn; Cmd+Shift+4) with a simulated capture; USB drives (insert, copy, safely eject); printing and cancelling a print job; copying files from a phone (simulated).

Module 12: Troubleshooting and searching for answers. Frozen programs; Task Manager (Ctrl+Shift+Esc) / Force Quit (Cmd+Option+Esc); restart; undo; accidental deletion; no internet; no sound. Then teach "how to describe a problem": copy the exact message, search it, and read the results. Include a simulated "something went wrong" scenario she must solve.

Module 13: Part 1 capstone. A multi-step real-life project, e.g.: create a folder named "আমার-কাজ", write and save a text file in it, search for a recipe in the simulated browser, take a screenshot, and email the file as an attachment. Show a progress checklist. On completion, generate a printable Bengali certificate ("সনদপত্র") with her name and date.
