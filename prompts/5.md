Windows flavor (PowerShell-style prompt, with cmd aliases like dir, cd, mkdir, type, cls) and Mac flavor (zsh-style prompt, with ls, cd, pwd, mkdir, touch, cat, clear). Supported commands (safe subset): pwd, ls/dir, cd (including .., ~, and absolute/relative paths), mkdir, touch/ni, cat/type, echo (including > redirection into files), clear/cls, and running pre-defined lesson scripts via `python file.py` and `node file.js`. Add: tab-completion for file/folder names, up/down arrow command history, a clear "dangerous commands are disabled in this practice terminal" message for things like rm -rf or del /s (with a Bengali explanation of why they are dangerous in real life). Unknown or mistyped commands produce friendly Bengali hints (e.g. suggest the nearest valid command). The step engine must be able to expect a typed command or a resulting file-system state.
